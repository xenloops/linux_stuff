

# VirtualBox

### Debian

1. Install from apt/apt-get
1. Download the Extension Pack from https://www.virtualbox.org/wiki/Downloads
1. Open VirtualBox and install the Extension Pack (Extensions tab, click Install, select file)
1. Open a terminal and enter ```sudo usermod -aG vboxusers $USER``` to allow things like USB recognition
1. Logout/login or reboot and enjoy VirtualBox
